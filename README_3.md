#Sales Data Analysis

این پروژه با هدف بررسی و تحلیل یک مجموعه‌داده فروش انجام شده است.

در ابتدا داده‌ها با Python بررسی شدند و محاسبات اصلی فروش روی تراکنش‌ها انجام شد. بعد از آن داده‌ها با Pandas پاک‌سازی و آماده تحلیل شدند. در ادامه چند تحلیل روی رفتار مشتریان و محصولات انجام شد، نمودارهای مختلف رسم شدند و برای دسته‌بندی مشتریان از K-Means استفاده شد. در پایان نیز چند Query با SQLite روی داده‌ها اجرا شد.

1. Python

در بخش Python، داده‌های فروش بدون استفاده از Pandas بررسی شدند و اطلاعات به صورت Dictionary در برنامه مورد استفاده قرار گرفتند.

مبلغ نهایی هر تراکنش با فرمول زیر محاسبه شد:

amount = quantity × unit_price × (1 - discount / 100)

برای جلوگیری از متوقف شدن برنامه در صورت وجود داده نامعتبر، تبدیل داده‌ها با "try/except" انجام شد.

موارد زیر نامعتبر در نظر گرفته شدند:

- "quantity <= 0"
- "unit_price <= 0"
- "discount < 0" یا "discount > 100"
- داده‌هایی که هنگام تبدیل به عدد باعث ایجاد خطا می‌شوند

برای محاسبه میانگین نیز فقط تراکنش‌هایی که معتبر بودند در نظر گرفته شدند و تعداد آن‌ها با "valid_count" محاسبه شد.

نتیجه اجرای بخش Python:

- مجموع فروش تراکنش‌های معتبر: 4185
- تعداد تراکنش‌های معتبر: 9
- میانگین مبلغ تراکنش‌های معتبر: 465

Choosing the Number of Clusters

برای پیدا کردن تعداد مناسب خوشه‌ها از Elbow Method استفاده شد.

در ابتدا محدوده تعداد خوشه‌ها بیشتر از تعداد مشتریان موجود بود و هنگام اجرای K-Means خطا ایجاد شد. این قسمت اصلاح شد و تعداد خوشه‌های 2 تا 4 بررسی شدند.

در نهایت تعداد خوشه‌ها برابر با 2 انتخاب شد:

optimal_k = 2

سپس مدل نهایی K-Means با دو خوشه اجرا شد و برای هر مشتری یک "cluster" اختصاص داده شد.

6. SQL

برای بررسی داده‌ها با SQL، از SQLite استفاده شد.

داده‌های فروش در جدول "sales" قرار گرفتند و پنج Query مختلف روی همان جدول اجرا شدند.

Query 1 — Filtering

نمایش تراکنش‌هایی که مبلغ نهایی آن‌ها بیشتر از 500 است:

SELECT *
FROM sales
WHERE amount > 500;

Query 2 — Aggregation

محاسبه مجموع فروش:

SELECT SUM(amount) AS total_sales
FROM sales;

Query 3 — Grouping and Sorting

محاسبه مجموع فروش برای هر محصول و مرتب‌سازی از بیشترین به کمترین:

SELECT product, SUM(amount) AS total_sales
FROM sales
GROUP BY product
ORDER BY total_sales DESC;

Query 4 — Grouping and Counting

محاسبه تعداد تراکنش‌های هر مشتری و مرتب‌سازی آن‌ها:

SELECT customer_id, COUNT(transaction_id) AS transaction_count
FROM sales
GROUP BY customer_id
ORDER BY transaction_count DESC;

Query 5 — Grouping and Average

محاسبه میانگین مبلغ خرید برای هر شهر:

SELECT city, AVG(amount) AS average_amount
FROM sales
GROUP BY city
ORDER BY average_amount DESC;

در پایان، اتصال SQLite بسته شد.
